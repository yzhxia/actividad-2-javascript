# Gestor de Tareas

Este es una tarea que hice para practicar. :D
La idea es tener una página sencilla donde pueda agregar tareas y organizarlas.

## ¿Qué puede hacer?
- Agregar tareas nuevas.
- Marcar tareas como completadas.
- Editar el nombre de las tareas.
- Eliminar tareas.
- Guardar las tareas para que sigan ahí cuando vuelva a abrir la página.

## Lenguajes que usé
- HTML
- CSS
- JavaScript
